## 1. Summary

1. **Two native families, two different damage models.**
   - `ADestructibleMiningRock : ADestructibleWorldActor` (DOM:9283): a rock with a normal
     `HealthComponent`, a tool gate on `DamageComponent.DamageModifiers` and an
     `ItemDropOnDestructionComponent`. It breaks once at 0 HP. **Exactly like a tree stump**, so the
     generic gather loop (and the emulated hit) works as is. HIGH.
   - `AOreNode : AWorldActor` (DOM:11556): **no HealthComponent**. It has `NodeHealth` (float),
     ore-chunk mesh components (`AllSpawnComponents` / `PopulatedSpawnComponents` /
     `EmptySpawnComponents`, `UOreNodeSpawnComponent : UStaticMeshComponent`), `MaxPopulatedSpawns`,
     the replicated SaveGame `UnpopulatedOres: TArray<int32>`, `HasAvailableResources()`,
     `GetResourceTag()` and a `RespawnComponent`. Mined chunk by chunk. The emulated hit
     (`DecreaseHealth`) cannot apply to it. HIGH (structure), MED (chunk model).
2. **The loaded stone rocks are `BP_OreNode_Stone_C`, which is a DestructibleMiningRock**, not an
   AOreNode, despite its name (136 loaded world-wide, 6 within 40 m of Luis). HP **75**, gate
   `DA_PickaxeOnly` (`BP_DamageModifier_SpecificWeapon_C`, RequiredTier **1**, RequiredCategory
   `Item.Equipment.Tool.Pickaxe`), drops `ITEM_Resources_Stone` **10-16** (MaximumGrouping 1, so
   10-16 world items of 1), `bDestroyActorOnZeroHealth=false` (it hides and respawns),
   RespawnComponent max 1. HIGH (LIVE).
3. **Rune essence:** `BP_MiningRock_RuneEssence_Static_A_C` (21 loaded; class name says "Static",
   the census lists it under DestructibleMiningRock): HP **60**, `DA_PickaxeOnly` tier 1, drops
   `ITEM_Rune_Essence` x5. And `BP_RuneEssenceGeyser_{B,C,D,F,J}_C : ARuneEssenceGeyser : AOreNode`
   (5 loaded): NodeHealth 1.0, 3 of 4 chunks populated, ResourceTag `Item.Resource.Ore.RuneEssence`,
   empty ItemDropComponent, RespawnComponent 3/3. HIGH (LIVE).
4. **Metal ore rocks were not loaded** around Luis (Brynmoor), so their classes are unknown. Their
   items are in the dump (section 3). The `DetectOre` spell data (`UDetectOreGameplayEffectData`:
   `OreNodeClass: TSubclassOf`, `MaxOreNodesToDetect`, `bLockInDetectedOreNodes`, DOM:18932) points at
   **AOreNode** as the class "Summon Stone Spirits" detects, which suggests metal veins are
   AOreNodes (chunk model), not DestructibleMiningRocks. MED. Read `OreNodeClass` live to settle it.
5. **Tool:** the pickaxe's primary is `PA_Attack_Pickaxe_C` -> `BP_Player_Pickaxe_Mine1_C`
   (damage 10, damage point 878 ms, next swing 1527 ms, stamina 6); **no special**. Damage
   multiplier per tier from the catalog (Stone 1.0 ... Bronze 3.4 ... Adamant 8.4, Rune 9.5). So a
   Bronze pickaxe breaks a stone rock (75 HP) in 3 hits (34 each). HIGH (catalog), MED (that the
   game's per-hit damage = 10 x multiplier, which matched Luis's adamant axe on logs exactly).

## 4. How it plugs into the gather loop

- `mod/body/resource_profiles.lua` has `stone` and `rune_essence` (verified classes) and
  `copper`, `tin`, `iron`, `coal`, `clay` with **guessed** class patterns (`OreNode_<Name>`, from the
  stone rock's naming). Each is one `rock(match, item, aliases)` line: root class
  `DestructibleMiningRock`, filter `alive` (HP > 0 and not hidden), attack `primary` (the pickaxe
  has no special), reach 2 m, no child stages, drops collected within 8 m.
- The tool check reads the live gate (`DamageComponent.DamageModifiers[...].RequiredTier/RequiredCategory`).
- **Gap: AOreNode veins.** If the metal ores are AOreNodes (summary 4), they need a profile kind
  with `filter = "alive"` (`HasAvailableResources()`, already in `sense.state_of`) and a progress
  signal other than HP (the `PopulatedSpawnComponents` count / `UnpopulatedOres` length, both
  readable). The emulated hit has no target there (no HealthComponent), so mining them needs the
  **native** hit, which needs the puppet's swing to carry an item instance
  (`FPlayerActionInstance.ActionGranter`, see DISCOVERIES "Gather"). Until then the gather loop
  will report `path_blocked` (swing_no_effect) for them; do not add AOreNode profiles before this.
