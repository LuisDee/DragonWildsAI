# Phase 4 (Body): what the reflection dump says

Date: 2026-10-25. Source: UE4SS dump of the dedicated server, build **26161880** (UE 5.6, game module `Dominion`), at `dumps/26161880/`. Nothing was run on the server for this note.

**How to read the references**
- `O:<n>` is line n of `UE4SS_ObjectDump.txt`.
- `CXX <file>:<n>` is `CXXHeaderDump/<file>`.
- `UHT <file>` is `UHTHeaderDump/Dominion/Public/<file>`. These have real return types, but their `.cpp` function bodies are empty stubs.
- `LT` is `luatypes/Dominion.lua`.

**Caveat on the dump.** The object dump was taken on an idle server, 2 minutes after boot, with no players connected.
- Only Blueprint classes that were already loaded appear in it. No passive animal or wolf class is loaded, so their class paths are **not** in the dump.
- No AI character instances exist yet. The AiDirector spawns creatures around players.
- `mod/scripts/body_probe.lua` (section 9) fills these gaps at runtime once Luis is connected.

## 0. Summary

1. **The game has a built-in follower system, and it runs on the server.**
   - `UFollowerComponent` sits on every player pawn (`BP_PlayerCharacter_C.BP_Components_Follower`). It has `ToggleFollower(UFollowerDataAsset*)`.
   - `ADominionPlayerCharacter.Follower` holds the spawned `ADominionAICharacter`.
   - One follower data asset is loaded: `DA_Kalphite_Friend`, a Kalphite summoned by the Pharaoh's Sceptre special.
   - Calling `ToggleFollower(DA_Kalphite_Friend)` on Luis's pawn from the server is the **shortest possible path to the Phase 4 gate**: native spawn, native follow, native replication. Try it first (T2).
2. **Any AI can be made to follow a player.**
   - `ADominionAICharacter:Confuse(AActor* InConfuser, bool bShouldFollow)` exists.
   - The ambient AI has a dedicated `UAIAmbientStateObject_Follow` state, tuned by `FollowAcceptanceRadius` and `FollowRunThresholdDistance` in `FAmbientComponentContext`.
   - So "follow Luis" for a spawned creature may be one call, with no `MoveTo` loop (T3).
3. **The game's own spawn function is reflected:** `UAsyncAction_DomSpawnAI::AsyncDomSpawnAIAtLocation(WorldContext, PlayerInstigator, NavMeshOriginActor, Origin, Rotation, TSoftClassPtr<ADominionAICharacter> AIClass, int32 PowerLevel)`. It is `BlueprintAuthorityOnly`. It is safer than raw `SpawnActor` because it runs the game's own setup (AI data asset, power level, fade-in, AI subsystem registration). The open question is how UE4SS marshals the `TSoftClassPtr` argument (T4).
4. **AI stack:**
   - Bodies: `ACharacter → ADominionCharacterBase → ADominionAICharacter → BP_DominionAICharacter_C → BP_AI_<Name>_Character_C`.
   - Movement component: `UAiMovementComponent`, which is a `UCharacterMovementComponent`.
   - Controllers: `AAIController → ADominionAIController` (with `UDominionPathFollowingComponent`) `→ BP_AI_<Name>_Controller_C`.
   - Behaviour is Dominion's own framework: alertness states, ambient movement state objects, `UDominionAIAction`, combat strategy components, `AAiDirector` spawning.
   - **No BehaviorTree, StateTree or Mass for characters.** No BT or StateTree asset is loaded. JagexMassAI only contains a navigation-state processor.
5. **Humanoid NPCs cannot walk.** `BP_BaseInteractableNPC_C → AInteractableNPC → AWorldActor → AActor`. These are static actors with a skeletal mesh, not Pawns. Wise Old Man, Death and Postie Pete are all of this kind. Drop them as body candidates. A humanoid walking body must be a `DominionAICharacter`, such as goblins or other humanoid AI; none was loaded at dump time.
6. **Navmesh:**
   - The navmesh exists, streamed with World Partition.
   - L_World has 6 `RecastNavMesh` actors (Default and Gigantic agents, 3 each), 27 `NavMeshBoundsVolume`s and 245 `AISpawnVolumeNavigationSeed`s.
   - `AAiDirector` tracks `NavmeshLoadingTimeTracker`.
   - No `NavigationDataChunkActor` was loaded while idle, so nav data is very likely present only in cells streamed around players. That is fine for a companion near Luis. Verify with the probe's `K2_ProjectPointToNavigation`.
7. **Replication:** creatures spawned by the director already replicate in normal multiplayer. A `DominionAICharacter` is therefore a much safer body than the `InteractableNPC`, whose `bReplicateMovement=false` was flagged in the earlier research. There is also an AI-specific relevance layer: `DesiredActivationRange` 100 m, `DesiredDeactivationRange` 110 m, `DesiredCullRange` 120 m, and `OverrideCullingSettings(...)`.

**Recommended first spawn experiment:** T2 in section 8. On Luis's pawn, server side, call `pawn:GetFollowerComponent():ToggleFollower(StaticFindObject(".../DA_Kalphite_Friend.DA_Kalphite_Friend"))`, then read `pawn.Follower`. Ask Luis whether a Kalphite appeared and follows him. Run the read-only probe (T1) just before it.
